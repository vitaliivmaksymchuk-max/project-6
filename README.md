# Практична робота № 6
**Тема:** Проєктування користувацьких інтерфейсів веб-додатків: моделювання станів екрана (Screen States) та архітектура дизайн-систем на основі дизайн-токенів.

## Реалізований функціонал
1. **Життєвий цикл станів екрана (`Screen States`)**:
   - `loading`: каркасна заглушка (Skeleton Screen) з CSS-анімацією мерехтіння.
   - `content`: сітка карток із можливістю фільтрації та видалення елементів.
   - `empty`: порожній стан із векторною SVG-іконкою та кнопкою відновлення списку.
   - `error`: діагностичне повідомлення про помилку з кнопкою повторного запиту.
2. **Асинхронна імітація та природні переходи**:
   - Використано `window.setTimeout` для симуляції мережевого запиту при натисканні «Оновити» або «Повторити спробу».
   - Автоматичний перехід у `empty` при видаленні всіх карток або введенні неіснуючого пошукового запиту.
3. **Трирівнева дизайн-система (`tokens.css`)**:
   - Рівень 1 (`Primitive Tokens`): базова палітра кольорів, шкала відступів, типографіка.
   - Рівень 2 (`Semantic Tokens`): функціональні ролі (`--bg-canvas`, `--text-primary`, `--color-primary`, `--color-danger`).
   - Рівень 3 (`Component Tokens`): токени кнопок, полів введення та карток.
   - Перемикання теми (`Light` / `Dark`) реалізовано виключно через перевизначення семантичних токенів у `[data-theme="dark"]`.
   - Додано окремий екран **UI-Kit / Дизайн-система** для демонстрації станів базових компонентів.
